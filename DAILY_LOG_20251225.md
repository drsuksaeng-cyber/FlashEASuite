## 🔧 **Technical Details**

### **Header Format Standardization:**

**Old Format:**
```cpp
//| FlashEASuite V2 - Description |
```

**New Format (SKN Standard):**
```cpp
//| SKN V 2.10 - Risk Enhanced 251225 13:30 |
```

---

### **Critical Path Rules (MUST FOLLOW):**

```
⚠️ CRITICAL: Include paths must be relative to MQL5 folder

CORRECT:
#include <Logic/StrategyManager.mqh>
#include <Risk/PositionSizingManager.mqh>

WRONG:
#include "Include/Logic/StrategyManager.mqh"  ❌
#include "../Include/Risk/..."                ❌
```

**Why This Matters:**
- MQL5 compiler looks in `MQL5/Include/` folder
- Wrong paths = compilation errors
- Even if file exists, compiler won't find it

---

### **Function Integration Pattern:**

**Problem:** StrategyManager.mqh expects `GetRiskBasedLotSize()`

**Solution Pattern:**
```cpp
// In ProgramC_Trader.mq5:

// 1. Main calculation function
double CalculateLotSize(double entry, double sl, double risk_percent)
{
   // Implementation here
   return calculated_lot;
}

// 2. Wrapper for StrategyManager
double GetRiskBasedLotSize(double entry, double sl, double risk_percent)
{
   return CalculateLotSize(entry, sl, risk_percent);
}
```

**Why Wrapper Needed:**
- StrategyManager calls GetRiskBasedLotSize()
- Main logic in CalculateLotSize() for clarity
- Wrapper provides backward compatibility

### **1. Debugging Methodology:**

**What Worked:**
```
Error → Ask "Why?" → Find root cause → Fix at source
```

**Example:**
```
Error: "GetRiskBasedLotSize must have a body"
↓
Ask: "Who calls this function?"
↓
Search: grep "GetRiskBasedLotSize" *.mqh
↓
Result: Not found in StrategyManager.mqh
↓
Conclusion: Unused → Delete declaration
↓
Fix: Remove lines 12-16
✅ Compile successful
```

**What Didn't Work:**
```
Error → Add implementation immediately (reactive)
↓
Result: Code bloat, unused functions
❌ Wrong approach
```
