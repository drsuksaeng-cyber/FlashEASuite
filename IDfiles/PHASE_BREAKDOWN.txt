## 📋 **PHASE 3: DLL Protection Layer**

### **Track C: DLL Development**

**Chat Assignment:** `CHAT_DLL_1`

**Deliverables:**
```
FlashEA_Security/
├── Security.cpp
├── Security.h
├── TradingParams.cpp
├── TradingParams.h
├── Challenge.cpp
├── Checksum.cpp
└── FlashEA_Security.dll
```

**Tasks:**
1. **CheckLicense()**
   - Read License.key
   - Verify RSA signature
   - Check HWID
   - Check expiry
   
2. **GetHWID()**
   - Get CPU Serial (WMI)
   - Get Disk Serial
   - Get Machine GUID (Registry)
   - Return SHA256 hash

3. **CalculateTradingParams()** (CRITICAL!)
   - Input: symbol, balance, license_path
   - Calculate: lot_size, grid_step, max_orders, tp, sl
   - Encrypt output
   - Return params

4. **VerifyPolicy()**
   - Parse JSON
   - Verify RSA signature
   - Return valid/invalid

5. **VerifyChallenge()** (Anti-Mock)
   - Compute HASH(random + license_secret + timestamp)
   - Compare with expected
   - Return valid/invalid

6. **VerifyDLLIntegrity()**
   - Calculate self-checksum
   - Compare with hardcoded hash
   - Return valid/invalid

**Dependencies:**
- OpenSSL (for RSA)
- RapidJSON (for JSON parsing)
- Windows API (for HWID)

**Include Paths in MQL5:**
```cpp
#import "FlashEA_Security.dll"
   int CheckLicense(string license_path);
   void GetHWID(string &output);
   int CalculateTradingParams(string license, string symbol, 
                              double balance, TradingParams &output);
#import
```
