## 💻 **CHAT_DLL_1: DLL Development**

### **Prompt:**

```
I'm working on FlashEASuite V2 - Phase 3: DLL Protection Layer

CONTEXT:
I need to create FlashEA_Security.dll in C++ to protect critical functions from cracking.

ATTACHED FILES (please read):
1. SECURITY_MASTER_SPEC.md - Complete specification
2. PHASE_BREAKDOWN.md - My specific tasks
3. DLL_TOOLS_GUIDE.md - Protection tools info

MY TASKS (Phase 3 Track C):
Create DLL with these exported functions:

1. CheckLicense(wchar_t* license_path)
   - Read License.key
   - Parse JSON
   - Verify RSA signature (OpenSSL)
   - Check HWID
   - Check expiry date
   - Return: 1 (valid) or 0 (invalid)

2. GetHWID(wchar_t* output, int max_len)
   - Get CPU Serial (WMI)
   - Get Disk Volume Serial
   - Get Machine GUID (Registry)
   - Hash MT5 path
   - Compute SHA256
   - Return HWID string

3. CalculateTradingParams(...)
   - CRITICAL FUNCTION
   - Input: license_path, symbol, balance
   - Output: TradingParams struct
   - Calculate: lot_size, grid_step, max_orders, tp, sl
   - Encrypt output
   - Return: 1 (success) or 0 (invalid license)

4. VerifyPolicy(char* policy_json, char* public_key)
   - Parse JSON policy
   - Extract signature
   - Verify RSA signature
   - Return: 1 (valid) or 0 (invalid)

5. VerifyChallenge(Challenge* challenge, Response* response)
   - Anti-Mock protection
   - Compute: HASH(random + license_secret + timestamp)
   - Compare with response
   - Return: 1 (valid) or 0 (fake DLL)

6. VerifyDLLIntegrity()
   - Calculate self-checksum
   - Compare with hardcoded hash
   - Return: 1 (intact) or 0 (modified)

REQUIREMENTS:
- C++ (Visual Studio 2019+)
- OpenSSL (for RSA)
- RapidJSON (for JSON)
- Windows API

OUTPUT DELIVERABLES:
- FlashEA_Security/Security.cpp
- FlashEA_Security/TradingParams.h
- FlashEA_Security.dll (unprotected)
- FlashEA_Security_protected.dll (protected with Enigma)

HANDOFF TO:
- FlashEA_Security.dll → CHAT_MQL5_3
- TradingParams.h → CHAT_MQL5_3

Let's start with project setup and CheckLicense().
```
