## 🔑 **HWID Generation Algorithm**

```cpp
string GenerateHWID()
{
    string components = "";
    
    // 1. CPU Serial (Win32 API)
    components += GetCPUSerial();
    
    // 2. Disk Volume Serial
    components += GetDiskVolumeSerial();
    
    // 3. Windows Machine GUID
    components += GetMachineGUID();
    
    // 4. MT5 Installation Path Hash
    components += HashString(TerminalInfoString(TERMINAL_PATH));
    
    // SHA256 Hash
    return SHA256(components);
}

string GenerateFingerprint()
{
    string fp = "";
    fp += GetHWID();
    fp += IntegerToString(AccountInfoInteger(ACCOUNT_LOGIN));
    fp += AccountInfoString(ACCOUNT_SERVER);
    fp += HashString(TerminalInfoString(TERMINAL_PATH));
    
    return SHA256(fp);
}
```

## 🛡️ **Policy Security Rules**

### **Anti-Replay Attack:**

1. **Timestamp Tolerance:** 5 minutes (300 seconds)
   ```cpp
   long policy_age = TimeCurrent() - policy.timestamp;
   if(policy_age > 300) return false;  // Too old
   if(policy_age < -60) return false;  // From future
   ```

2. **Nonce (One-Time Use):**
   ```cpp
   // Policy must have unique nonce (UUID v4)
   if(IsNonceUsed(policy.nonce)) return false;
   
   // After verification, store nonce
   StoreNonce(policy.nonce);
   ```

3. **Sequence Number:**
   ```cpp
   // Policy sequence must increment
   if(policy.sequence <= g_last_sequence) return false;
   
   // Update after verification
   g_last_sequence = policy.sequence;
   ```

## 🔐 **RSA Key Generation (Python)**

```python
from cryptography.hazmat.primitives.asymmetric import rsa
from cryptography.hazmat.primitives import serialization

# Generate RSA key pair (2048-bit)
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048
)

public_key = private_key.public_key()

# Save Private Key (Server only - SECRET!)
with open("server_private.pem", "wb") as f:
    f.write(private_key.private_bytes(
        encoding=serialization.Encoding.PEM,
        format=serialization.PrivateFormat.PKCS8,
        encryption_algorithm=serialization.NoEncryption()
    ))

# Save Public Key (Embed in EA)
with open("server_public.pem", "wb") as f:
    f.write(public_key.public_bytes(
        encoding=serialization.Encoding.PEM,
        format=serialization.PublicFormat.SubjectPublicKeyInfo
    ))
```
