### ปัญหา
Brain ที่รันอยู่ (`02_Brain/main.py` + `core/strategy/engine.py v2.4`) คือ **V5 Engine (Spike/Grid)**

| | Brain V5 | Trader V6 ต้องการ |
|-|----------|------------------|
| Message type ส่งออก | type 2 (MSG_TYPE_POLICY) | type 10 (CONFIG_PUSH) |
| ผลลัพธ์ | Trader ignore ทิ้ง | `Configs recv:0` ตลอด |

### ไฟล์ที่เกี่ยวข้อง

```
Trader รอรับ (MQL5):
  case MSG_CONFIG_PUSH (10): → ApplyConfigPushV2()
  case MSG_INITIAL_CONFIG (12): → switch to ONLINE mode
  case MSG_TYPE_POLICY (2): break;  ← V5 messages ถูก ignore

Brain V5 ส่งได้:
  core/strategy/engine.py → ส่ง type=2 policy เท่านั้น

Brain V6 ต้องสร้าง:
  config_push/config_builder.py  ← ConfigBuilder (มีอยู่แล้ว)
  config_push/config_pusher.py   ← ConfigPusher ZMQ PUB (มีอยู่แล้ว)
  core/protocol_handler.py       ← ProtocolHandler V6 (มีอยู่แล้ว)
```

## บทเรียนวันนี้ (2026-03-09)

### 1. Brain V5 ≠ Trader V6 — ต้องเช็ค message type เสมอ
- **ปัญหา**: Brain V5 ส่ง type=2 (policy), Trader V6 รอ type=10/12 (CONFIG_PUSH)
- **อาการ**: `Configs recv:0` แม้ Brain ONLINE
- **วิธีเช็ค**: ดู Trader Journal หา `Switched → ONLINE MODE` ถ้าไม่มี = Brain ส่งผิด format
- **บทเรียน**: ก่อน live test ต้องยืนยัน Brain version ตรงกับ Trader version

### 2. `Configs recv:0` + `Regime: UNKNOWN` ใน STANDALONE = ปกติ
- **ความหมาย**: ไม่มี Brain V6 ส่ง CONFIG_PUSH มาให้
- **ผลต่อ trade**: S06/S14 (standalone=true) ยังทำงานได้ — ใช้ค่า default hardcoded
- **ไม่ต้องตกใจ**: Strategies ยังรัน Analyze() และสร้าง signal ตามปกติ

### 3. วิธีอ่าน MT5 Journal ถูกต้อง
- Init messages (`[StrategyManager] S06 Init OK`) → อยู่ที่ **ต้นสุดของ Journal** (scroll ขึ้น)
- ตรวจเร็ว: ดู `Registered: ✅ YES` ใน V6 STATUS แทน
- `Strategies: 1/16` = จำนวน enabled (ไม่ใช่จำนวน init สำเร็จ)

### 4. ZMQ "Address in use" = Brain เก่ายังไม่ตาย
- **อาการ**: Brain ใหม่ start แล้ว error `Address in use (addr=tcp://127.0.0.1:7778)`
- **แก้**: `netstat -ano | findstr ":7778"` แล้ว `taskkill /F /PID XXXX`
- **หรือ**: `Get-Process python | Stop-Process -Force`

### 5. Brain main.py มี live dashboard — Ctrl+C ใช้เพื่อ capture log เท่านั้น
- Brain **ไม่ได้หยุดเอง** — ถ้าปล่อยรันต่อจะแสดง live dashboard table ตลอดเวลา
- การหยุดด้วย Ctrl+C ในการทดสอบวันนี้ = หยุดเพื่อ capture text log ให้อ่านได้
- Brain ต้องเปิด terminal ค้างไว้ขณะใช้งานจริง
