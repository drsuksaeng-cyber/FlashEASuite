  1. ภาพรวมระบบ (SYSTEM OVERVIEW)
================================================================================

FlashEASuite V2 คือระบบเทรดอัตโนมัติแบบ Hybrid ที่ประกอบด้วย 3 components
หลักที่ทำงานร่วมกันผ่าน ZeroMQ messaging:

  ┌────────────────┐  Port 7777  ┌────────────────┐  Port 7778  ┌────────────────┐
  │  PROGRAM A     │ ──────────► │  PROGRAM B     │ ──────────► │  PROGRAM C     │
  │  FeederEA      │   ZMQ PUB  │  Python Brain  │   ZMQ PUB  │  Trader EA     │
  │  (MQL5)        │             │  (Python 3.10) │             │  (MQL5)        │
  └────────────────┘             └────────┬───────┘             └───────┬────────┘
                                          │                             │
                                          └──────────────── ◄───────────┘
                                               Port 7779 (Feedback / TRADE_REPORT)

  Program A (FeederEA)
  ─────────────────────
  - ส่ง tick data + OHLC + indicator data จาก MT5
  - ZMQ PUB port 7777 ทุก 100ms ต่อ symbol
  - รองรับ 28+ symbols พร้อมกัน

  Program B (Python Brain)
  ────────────────────────
  - รับ tick data → Regime Classification → Strategy Selection
  - ส่ง CONFIG_PUSH (type=10) ไปให้ Trader ทุก cycle
  - 3 Threads: Ingestion, StrategyEngine, ExecutionListener
  - Standalone fallback: ถ้า disconnect จะส่ง default params

  Program C (ProgramC_Trader)
  ────────────────────────────
  - รับ CONFIG_PUSH → เปิด/ปิด strategies ตาม Brain directive
  - 16 Strategies + 19 MM Methods ทำงานใน MQL5 (latency = 0)
  - ส่ง TRADE_REPORT กลับให้ Brain เพื่อ feedback loop
  - Standalone Mode: ถ้า Brain ปิด → ใช้ StandaloneSelector

  ZMQ Ports Summary:
  ──────────────────
    7777  = FeederEA → Brain (TICK/OHLC/INDICATOR data)
    7778  = Brain → Trader   (CONFIG_PUSH policies)
    7779  = Trader → Brain   (TRADE_REPORT feedback)

  CONFIG_PUSH Format (type=10 array):
    [type, ts, symbol, strategy, entry, lot, max_orders, tp, sl, confidence, risk_mult]

================================================================================

  Step 1: วาง Project Folder
  ──────────────────────────

    C:\Users\<YOU>\AppData\Roaming\MetaQuotes\Terminal\<TERMINAL_ID>\MQL5\Experts\

  หา path ใน MetaEditor: File → Open Data Folder

  Structure ที่ต้องมี:
    FlashEASuite_V2/
    ├── 01_Feeder/Src/FeederEA.mq5          ← Program A
    ├── 02_Brain/main.py                     ← Program B entry point
    ├── 02_Brain/core/                       ← Python modules
    ├── 03_Trader/ProgramC_Trader.mq5        ← Program C
    ├── Include/Logic/                       ← Strategy headers
    ├── Include/Network/Protocol/            ← ZMQ protocol
    ├── Include/Risk/RiskGuardian.mqh        ← Risk management

  ──────────────────────
  Copy libzmq.dll และ libsodium.dll ไปที่:

    1. MetaEditor → Navigator → Experts → FlashEASuite_V2 → 01_Feeder

    1. Navigator → Experts → FlashEASuite_V2 → 03_Trader

    3. กด F7 → ✅ 0 errors

    [✅] Allow algorithmic trading

  5. การปิดระบบ (SYSTEM SHUTDOWN)
================================================================================

  ลำดับปกติ (Graceful Shutdown):
  ────────────────────────────────
    1. ปิด Trader EA  (Remove จาก chart)
    2. ปิด FeederEA   (Remove จาก chart)
    3. ปิด Python Brain:  start_flashea.bat stop
    4. ปิด Health Monitor: Ctrl+C
    5. ปิด MT5 ตามปกติ

  ⚠️ ห้ามปิด Brain ขณะที่มี open positions อยู่

  Emergency Shutdown Levels:
  ──────────────────────────
  🔴 Level 1 — หยุดเทรดทันที (5 วินาที)
    MT5 → กดปุ่ม AutoTrading ให้เป็นสีแดง
    → EA ทุกตัวหยุดส่ง order ใหม่ แต่ยังทำงานอยู่

  🔴 Level 2 — ถอด EA (30 วินาที)
    MT5 → chart Trader → Right-click → Expert Advisors → Remove
    MT5 → chart Feeder → Right-click → Expert Advisors → Remove
    → ZMQ connections ปิด

  🔴 Level 3 — ปิดทั้งระบบ (1 นาที)
    start_flashea.bat stop
    Ctrl+C ที่ Health Monitor window
    ปิด MetaTrader 5

  🔴 Level 4 — Force Kill ฉุกเฉิน
    taskkill /im python.exe /f
    taskkill /im terminal64.exe /f
    ⚠️ หลัง Force Kill ต้อง restart ทั้งระบบตามลำดับ Step 1-6

  ปิด Open Positions:
  ────────────────────
    MT5 → Trade tab (ล่างสุด) → Right-click position → Close Position
    หรือ Close All: Right-click → Close All Positions

  │ python --version          │ ต้อง 3.8+; ถ้าไม่มี ติดตั้ง Python           │

      start_flashea.bat

  10. ขั้นตอนฉุกเฉิน (EMERGENCY PROCEDURES)
================================================================================

  Scenario A: Drawdown เกิน 10%
  ──────────────────────────────
    1. MT5 → AutoTrading OFF (สีแดง) ← ทันที
    2. ดู open positions ทั้งหมด
    3. ตัดสินใจ: Close all หรือ รอ?
    4. Review: สาเหตุที่ drawdown สูง
    5. ปรับ lot size ลง หรือ เปลี่ยน MM method
    6. กลับมาเทรดด้วย lot เล็กลงก่อน

  Scenario B: Python Brain Crash กลางดึก
  ────────────────────────────────────────
    - Health Monitor จะ auto-restart Brain (max 3 ครั้ง)
    - ถ้าไม่ restart:
        start_flashea.bat stop
        start_flashea.bat
    - Trader จะ switch เป็น Standalone Mode อัตโนมัติ
    - ตรวจ logs\health.log เพื่อหาสาเหตุ

  Scenario C: MT5 Crash
  ──────────────────────
    1. Restart MT5
    2. MT5 จะ auto-attach EA ที่เคย attach ไว้ (จำ state)
    3. ตรวจ: Experts tab ว่า FeederEA และ Trader re-attach แล้ว
    4. ถ้าไม่ auto-attach: ทำ STEP 3 และ STEP 4 อีกครั้ง

  Scenario D: News Spike / Flash Crash
  ──────────────────────────────────────
    1. MT5 → AutoTrading OFF ทันที
    2. รอจน spread กลับปกติ (< 2x ค่าปกติ)
    3. ปิด positions ที่ขาดทุนหนักถ้าจำเป็น
    4. เปิด AutoTrading หลัง spike จบ (โดยปกติ < 5 นาที)
    Note: S16_Spike จะตรวจ spread อัตโนมัติ แต่ manual override ดีกว่า

  Scenario E: ระบบ Overload / CPU spike
  ──────────────────────────────────────
    1. ตรวจ Task Manager: Python CPU > 50% ผิดปกติ
    2. start_flashea.bat stop แล้ว start ใหม่
    3. ถ้ายังสูง: ลด symbols ใน FeederEA
    4. ตรวจ logs สำหรับ infinite loop หรือ exception storm

  Emergency Contact Summary:
  ──────────────────────────
  ┌──────────────────────────────┬──────────────────────────────────────────────┐
  │ สถานการณ์                    │ Action                                       │
  ├──────────────────────────────┼──────────────────────────────────────────────┤
  │ Brain crash                  │ Health monitor auto-restart (max 3 ครั้ง)   │
  │ Brain ไม่ restart            │ start_flashea.bat stop แล้ว start ใหม่      │
  │ MT5 crash                    │ Restart MT5 → EA จะ re-attach อัตโนมัติ    │
  │ ปิดทุกอย่างเร่งด่วน         │ start_flashea.bat stop → ปิด MT5            │
  │ Port conflict                │ netstat -ano | find "777" → taskkill /pid   │
  │ Drawdown > 20%               │ Level 1 stop → Close positions → Review     │
  └──────────────────────────────┴──────────────────────────────────────────────┘

  Do's และ Don'ts สำหรับการดำเนินงาน:
  ──────────────────────────────────────
  ✅ DO:
    - เริ่มด้วย Demo account อย่างน้อย 1 สัปดาห์
    - ใช้ lot size เล็ก (0.01) จนกว่าจะมั่นใจ
    - เปิด Health Monitor ตลอดเวลา
    - ตั้ง Daily Loss Limit ใน RiskGuardian (default 2%)
    - จด trade journal ทุกวัน
    - Backup folder ทุกสัปดาห์

  ❌ DON'T:
    - อย่าเริ่ม Live โดยไม่ผ่าน Demo
    - อย่าเพิ่ม lot size โดยไม่ดู performance ก่อน
    - อย่าแก้โค้ดขณะระบบทำงาน (ปิด EA ก่อน)
    - อย่าปิด Brain ขณะมี open positions
    - อย่าเพิกเฉย Health Monitor warnings
    - อย่ารัน Optimization โดยไม่ตรวจ S16 memory ก่อน
