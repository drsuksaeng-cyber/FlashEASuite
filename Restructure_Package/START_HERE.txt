## 🐛 Troubleshooting:

### ปัญหา: "Please run this script from FlashEASuite_V2 root directory"

สาเหตุ: รัน script ไม่ใช่ที่ root directory

แก้ไข:
- ต้อง cd ไปที่ FlashEASuite_V2\ ก่อน
- ต้องมีโฟลเดอร์ Include\ ใน directory เดียวกัน

---

### ปัญหา: ไม่มีโฟลเดอร์ Restructure_Package\

สาเหตุ: แตก ZIP ผิดที่

แก้ไข:
- แตก ZIP ใน FlashEASuite_V2\
- หรือ copy Restructure_Package\ เข้าไปใน FlashEASuite_V2\

---

### ปัญหา: Test ไม่ compile

สาเหตุ: ไฟล์ไม่ครบ

แก้ไข:
- ตรวจสอบ Include\Risk\*.mqh มีครบ 3 files
- ตรวจสอบ Tester\*.mq5 มีครบ 3 files
