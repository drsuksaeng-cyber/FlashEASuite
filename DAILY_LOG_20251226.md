## 📚 Lessons Learned

### **1. Include Path Rules (MEMORIZE!)**
```
"" = Relative path from current file
<> = System path (MQL5/Include/ ONLY)

Project files = ALWAYS use ""
System files  = ALWAYS use <>
```

### **2. Always Check Structure First**
```
Before suggesting ANY path:
1. View tree structure
2. Locate source file
3. Locate target file
4. Calculate relative path
5. Choose correct syntax
```

### **3. Don't Assume - Verify**
```
❌ Bad:  Assume Include is in subfolder
✅ Good: Check tree structure first

❌ Bad:  Use <> because "it should work"
✅ Good: Verify actual file location
```

### **4. Learn from Repetition**
```
If error happens 3+ times with same fix:
→ STOP
→ Approach is fundamentally wrong
→ Ask user for clarification
→ Get tree structure
→ Start fresh
```

## 💡 Technical Insights

### **MQL5 Include Search Order:**

**For `<File.mqh>`:**
```
1. MQL5/Include/
2. Terminal/Common/Include/
3. STOP - doesn't search elsewhere!
```

**For `"File.mqh"`:**
```
1. Same directory as current file
2. Relative paths work (../, ../../, etc.)
```

### **FlashEASuite V2 Specific:**

**Project Include Location:**
```
MQL5/Experts/FlashEASuite_V2/Include/
```

**NOT in:**
```
MQL5/Include/  ← This is system Include
```

**Therefore:**
```
All project files MUST use "" not <>
```
